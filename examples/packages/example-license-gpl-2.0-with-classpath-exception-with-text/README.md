# @callstack/example-license-gpl-2.0-with-classpath-exception-with-text

This is a test package with the license expression `GPL-2.0-only WITH Classpath-exception-2.0`, shipping a `COPYING` file, for the needs of example tester projects in this monorepository to depend on, to manually test how the native license screens (Android and iOS) display it.

Expected: the name keeps the exception (`GPL-2.0-only WITH Classpath-exception-2.0`), with the `COPYING` text.
