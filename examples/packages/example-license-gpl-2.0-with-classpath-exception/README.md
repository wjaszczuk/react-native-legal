# @callstack/example-license-gpl-2.0-with-classpath-exception

This is a test package with the license `GPL-2.0-only WITH Classpath-exception-2.0`, for the needs of example tester projects in this monorepository to depend on, to test that license-kit parses, renders and classifies SPDX license expressions.

Expected category: strong copyleft with both OR Policies. The License Exception is shown in every rendered output.
