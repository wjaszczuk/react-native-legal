# @callstack/example-license-mit-or-apache-2.0-single-file

This is a test package with the license expression `MIT OR Apache-2.0`, shipping a `LICENSE` file, for the needs of example tester projects in this monorepository to depend on, to manually test how the native license screens (Android and iOS) display it.

Expected: Android lists `MIT` and `Apache-2.0`, both with the single text; iOS shows that text once.
