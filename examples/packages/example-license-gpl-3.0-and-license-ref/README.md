# @callstack/example-license-gpl-3.0-and-license-ref

This is a test package with the license `GPL-3.0-only AND LicenseRef-Custom`, for the needs of example tester projects in this monorepository to depend on, to test that license-kit parses, renders and classifies SPDX license expressions.

Expected category: unknown with both OR Policies, but `copyleft` still exits with 1, because the strong copyleft is unavoidable.
