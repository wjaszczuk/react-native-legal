# @callstack/example-license-lgpl-2.1-and-license-ref

This is a test package with the license `LGPL-2.1-only AND LicenseRef-Custom`, for the needs of example tester projects in this monorepository to depend on, to test that `copyleft` reports weak copyleft that is also an Unidentified License.

Expected category: unknown with both OR Policies. `copyleft` lists it as weak copyleft and as an Unidentified License, since the custom license may be strong copyleft.
