# @callstack/example-license-lgpl-3.0-plus

This is a test package with the license expression `LGPL-3.0+`, shipping a `LICENSE.txt` file, for the needs of example tester projects in this monorepository to depend on, to manually test how the native license screens (Android and iOS) display it.

Expected: the license is shown as `LGPL-3.0-or-later`, with the `LICENSE.txt` text.
